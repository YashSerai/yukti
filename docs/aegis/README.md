# Yukti Aegis Workspace

This directory is Yukti's product and engineering control plane. Specs define approved behavior, plans define executable work, and evidence records reusable verification. Product code and transient test output do not belong here.

## Structure

- `specs/`: approved product and architecture contracts
- `plans/`: implementation plans
- `baseline/`: evidence snapshots used for alignment checks
- `INDEX.md`: canonical index of active artifacts
- `BASELINE-GOVERNANCE.md`: rules for distinguishing design defects from implementation drift
